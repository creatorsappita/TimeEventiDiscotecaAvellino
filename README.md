# TIME Eventi Discoteca Avellino - Demo Premium

Sito statico dimostrativo, responsive e pronto per Vercel.

## Pubblicazione

1. Caricare tutti i file e le cartelle nella radice del repository GitHub.
2. Vercel eseguirà automaticamente il nuovo deploy.
3. Se Vercel chiede un framework, selezionare **Other**.

## Prima della presentazione

Sostituire in tutti i file:

- `390000000000` con il numero WhatsApp ufficiale completo di prefisso, senza `+`.
- Date, titoli e descrizioni degli eventi.
- Indirizzo, mappa e collegamenti social.
- La dicitura “Demo non ufficiale” solo dopo l'autorizzazione del locale.

## Immagini

La demo usa visual grafici creati con CSS, quindi non contiene immagini esterne o protette. Le foto ufficiali potranno essere aggiunte nella cartella `assets/images` e collegate successivamente.

## File principali

- `index.html`: homepage premium
- `eventi.html`: eventi
- `gallery.html`: gallery dimostrativa
- `prenotazioni.html`: richiesta tavolo via WhatsApp
- `contatti.html`: contatti
- `assets/css/style.css`: stile completo
- `assets/js/main.js`: menu, animazioni e modulo WhatsApp
